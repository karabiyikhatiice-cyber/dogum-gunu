# 🎂 Doğum Günü Site Template

Bu şablonu kişiselleştirmek için:

1. `index.html` dosyasını aç.
2. `ARKADAŞININ ADI` yazan yerleri arkadaşının adıyla değiştir.
3. Mektubu ve timeline yazılarını değiştir.
4. `images` klasörüne kendi fotoğraflarını koy.
5. Fotoğrafların adlarını `foto1.jpg`, `foto2.jpg`, `foto3.jpg`, `foto4.jpg` yap.
6. `index.html` dosyasına çift tıklayarak siteyi tarayıcıda aç.

## Daha fazla fotoğraf
`index.html` içindeki `.photo-card` bloklarından birini kopyalayıp yeni fotoğraf ekleyebilirsin.

## Not
Bu ilk template daha çok "duygusal anı albümü" konseptinde.
İkinci arkadaş için tamamen farklı, oyun/quiz temalı bir site tasarlayabiliriz.
